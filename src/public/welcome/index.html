Become a DNS peer

ODiN DNS is a mesh of independent peer servers run by users. If one peer goes offline, the rest keep resolving.

  1. Clone the repo and install dependencies: npm install
  2. Start the DNS peer backend: npm run start:dns
  3. Set your public hostname and register with the network: 
    export PEER_REGISTER_URL=""
export PEER_HOST="your-public-hostname.example.com"
export PEER_COLO="EWR"          # optional, your nearest airport code
npm run start:dns
  4. Open UDP port 3001 (or your DNS_PORT) on your firewall
  5. Point clients at your peer or let them auto-discover the nearest via this page

Your peer heartbeats every 5 minutes. It is removed from the network after 1 hour without a heartbeat.
